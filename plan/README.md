## Quy ước

- Sinh plan bằng `/write-plan`, chạy bằng `/execute-plan`.
- Plan phải có: **Context** (vì sao), file cụ thể sẽ tạo/sửa, và **Verification** (lệnh chạy thật được).
- Checkbox `- [ ]` cập nhật trong lúc thực hiện; xong thì đổi cột Trạng thái ở bảng trên.
- Plan đã xong **không xoá** - giữ làm lịch sử quyết định.
